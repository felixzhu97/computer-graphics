# WebGPU 游戏项目

基于 Next.js 和 WebGPU 的 3D 游戏项目。

## 技术栈

- 框架: Next.js
- 图形: WebGPU
- UI: React + TypeScript
- 样式: Tailwind CSS

## 运行项目

1. 安装依赖:

```bash
npm install
# 或
yarn install
# 或
pnpm install
```

2. 启动开发服务器:

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
```

3. 打开浏览器访问: http://localhost:3000

## 项目结构

- `/app`: Next.js 应用路由
- `/components`: React 组件
- `/public`: 静态资源
- `/styles`: 全局样式
- `/docs`: 系统架构文档(C4 模型)
