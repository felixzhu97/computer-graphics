# Contributing

Thanks for your interest in the computer-graphics guide repository.

## Development

This repository holds multiple graphics demos and guides under separate
subdirectories. Pick the relevant project folder for your change.

## Pull requests

1. Branch from `master`.
2. Keep changes focused on a single demo or guide when possible.
3. Match the existing folder layout and coding style of that subdirectory.
4. Open a PR against `master` with a clear description of why the change is
   needed.

## Code of Conduct

Participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
